1. 주요 데이터셋 순위 (Your Project 관점)
================================================================================

🥇 1순위: DMD (Driver Monitoring Dataset)
   ├─ 41시간 RGB+IR+Depth, 37명 피험자
   ├─ 명확한 occlusion 주석 (이 프로젝트의 핵심!)
   ├─ 다중 카메라 동기화 (얼굴, 몸, 손)
   ├─ Gaze 지역 레이블 포함
   └─ URL: https://dmd.vicomtech.org/

🥈 2순위: DriveAHead
   ├─ 100만 개 IR 이미지 (가장 큼)
   ├─ Yaw/Pitch/Roll 포즈 주석
   ├─ 프레임 레벨 occlusion 플래그
   ├─ 모션캡처 ground truth
   └─ Head pose 사전학습에 이상적

🥉 3순위: DAD (Driver Anomaly Detection)
   ├─ 다중 모달: IR+Depth (당신이 필요한 것!)
   ├─ 다중 뷰: 전면 + 상단 (occlusion 문제 해결)
   ├─ 95GB 데이터
   └─ Contrastive learning 기반

4. 데이터 증강 (IR 도메인 특화)
================================================================================

합성 Occlusion (Priority: HIGH)
───────────────────────────────
✓ Random Erasing: 무작위 사각형 영역 제거
✓ Cutout: 정사각형 영역 제거
✓ Object Overlay: 선글라스, 마스크, 손 합성 오버레이

조명 변화 시뮬레이션 (Priority: HIGH)
─────────────────────────────────────
✓ 밝기 조정 (±20-40%)
✓ 대비 향상 (Contrast enhancement)
✓ 감마 보정 (Gamma correction)
✓ CLAHE (Contrast Limited Adaptive Histogram Equalization)

IR 특화 기법 (Priority: MEDIUM)
──────────────────────────────
✓ Thermal 컬러화 (PearlGAN): IR→RGB 변환
  → 더 많은 RGB 데이터 활용 가능
  → https://github.com/FuyaLuo/PearlGAN
✓ Domain Adaptation via Style Transfer
  → RGB→IR 기능 전이
✓ TE-GAN: IR 명암 + 노이즈 제거

GAN 기반 생성 (Priority: LOW, 여유시 시도)
───────────────────────────────
• Pix2Pix: 쌍을 이룬 RGB-IR 데이터 필요
• CycleGAN: 쌍 없이 도메인 변환
• PearlGAN: 야간 이미지에 특화

8. 핵심 성공 요소
================================================================================

✓ Custom failure dataset (5-10시간)
  → SOTA 공개 데이터에 없는 실제 실패 사례 = 당신의 경쟁 우위

✓ Occlusion 라벨링 (DMD + 당신 데이터)
  → 대부분의 논문이 무시 = 차별화 포인트

✓ 신뢰도 기반 동적 융합
  → 다양한 failure mode에 대한 degraded mode 동작
  → FPR 감소 = 실제 차량 적용성 증대

✓ 반자동 주석 (CVAT + AI)
  → 30-60시간으로 15시간 데이터 처리 = 시간 효율성

✓ IR 특화 전처리
  → RGB-only 모델과 성능 차이 최소화

9. 현실적 벤치마크 기대값
================================================================================

공개 벤치마크 vs 실제 차량:
─────────────────────────────
• 공개 데이터 성능: ~95-99% (대부분 SOTA가 보고)
• 실제 실패 시나리오: -3~5% 성능 저하 예상
• IR 기반 (RGB 대비): -5~10% 추가 저하 가능
• 다중 branch 융합: +2~4% 회복 가능

따라서 현실적 목표:
─────────────────
• 공개 데이터: 95-96% (보수적)
• 당신의 실패 데이터: 90-93% (구체적 달성 가능)
• 이것도 충분히 SOTA 수준이며, 특히 occlusion + IR 조건에서 우수

최종 조언
================================================================================

당신의 프로젝트가 다른 DMS 논문과 다른 점:

1️⃣ IR + 조명 변화 대응 (기존: 주로 RGB)
2️⃣ 명시적 occlusion 라벨링 (기존: 대부분 무시)
3️⃣ 다중 branch 신뢰도 융합 (기존: 단순 앙상블)
4️⃣ FPR 감소에 초점 (기존: 정확도만 중시)
5️⃣ Custom failure dataset (기존: 공개 데이터만 사용)

이 5가지가 당신의 차별화 포인트이자 논문의 핵심 기여입니다.

각 주차마다 위 문서들을 참고하면서 진행하면:
→ 15주 안에 충분히 95% 정확도 + 신뢰도 융합 시스템 완성 가능
→ 논문과 실무 양쪽에서 가치 있는 결과물 도출 가능
