| Latency | <0.3s | Typical | ✓ 가능 |
| Recall | 90% | ~85-95% | ✓ 달성 가능 |

## 📞 자주 묻는 질문

**Q: 어느 데이터셋을 먼저 써야 하나?**
A: DMD로 시작. 가장 완전한 주석과 IR이 있음. → 빠른참고가이드 섹션 1 참고

**Q: 주석에 얼마나 시간이 걸리나?**
A: 반자동으로 15시간 비디오당 30-60시간 (5명: 각 6-12시간)
→ 기술참고자료의 시간 추정표 참고

**Q: 신뢰도 융합은 어떻게 구현하나?**
A: 기술참고자료의 ConfidenceAwareFusion 클래스 예제 참고

**Q: 95% 정확도 달성 가능한가?**
A: 네, SOTA에서 95.59%를 달성했으므로 충분히 가능
→ 빠른참고가이드 섹션 2 참고

**Q: 어느 증강 기법부터 시작해야 하나?**
A: Priority HIGH 먼저 (합성 occlusion, 조명 시뮬레이션)
→ 빠른참고가이드 섹션 4 참고

## 🎓 최종 팁

당신의 프로젝트가 다른 DMS 논문과 다른 이유:

1. **IR + 조명 변화** (기존: 주로 RGB)
2. **명시적 Occlusion 라벨링** (기존: 대부분 무시)
3. **다중 Branch 신뢰도 융합** (기존: 단순 앙상블)
4. **FPR 감소에 초점** (기존: 정확도만)
5. **Custom Failure Dataset** (기존: 공개 데이터만)

이 5가지가 당신의 논문 기여입니다. 성공을 기원합니다!
