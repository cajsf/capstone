# 🚗 Scuppy (스꾸삐): 강건한 운전자 모니터링 시스템 (DMS)

> **2026학년도 1학기 인공지능학과 캡스톤 디자인 프로젝트**
> **"저조도 및 안면 가려짐 환경에서도 동작을 유지하는 신뢰도 기반 3D 시선 추정 시스템"**
---

## 🌟 프로젝트 개요
최근 교통사고의 주요 원인으로 지적되는 졸음운전 및 주의분산 행동을 실시간으로 감지합니다.
본 프로젝트는 기존 시스템의 한계인 **야간 저조도, 급격한 조도 변화, 마스크/선글라스 등에 의한 안면 가려짐** 상황에서도 끊김 없이 동작하는 **IR(적외선) 기반 강건한 DMS** 구현을 목표로 합니다.

**핵심 장비**: USB IR(적외선) 카메라 + NVIDIA GPU 탑재 노트북.
**주요 목표**: 야간 저조도, 마스크/선글라스 차폐 상황에서도 중단 없는 모니터링 제공.

## 👥 팀원 및 역할 분담 (New Roles)
팀원들의 희망 파트와 효율적인 개발을 위해 **얼굴 / 포즈 / 시스템 보조**의 3개 팀으로 재편성하였습니다.

| 파트 | 담당 팀원 | 주요 업무 및 책임 |
| :--- | :--- | :--- |  
| **얼굴 (Face)** | **유건(PM), 강성찬** | IR 기반 얼굴/특징점 탐지, GazeD(확산 모델) 구현, 3D 시선 벡터 최적화 |  
| **포즈 (Pose)** | **황영인, 이수찬** | 상반신 포즈 추정, 차폐(선글라스/마스크) 판별 로직, Failure 데이터셋 기획 및 촬영 |  
| **시스템 보조 (Support)** | **강민성** | 전체 시스템 베이스라인(Back/Front) 구축, TensorRT 가속화 통합, 팀별 기술 지원 및 UI 개발 |  

## 🚀 핵심 기술 (Key Features)  
**IR 적응형 전처리**: 저조도 IR 영상의 밝기/대비를 최적화하여 특징점 검출력 강화.  
**GazeD 3D 시선 추정**: 확산 모델의 역과정(Reverse Process) 최적화를 통한 정밀 시선 분석.  
**신뢰도 기반 동적 융합**: 얼굴과 포즈 정보의 confidence score를 비교하여 정보 손실 시에도 동작 유지.  
**실시간 경고 시스템**: 이상행동(졸음, 주의분산) 감지 시 즉각적인 시각/청각 피드백 제공.  

#📈 정량적 성능 목표
* **정확도**: 통합 환경에서 **95% 이상** 달성  
* **시선 오차**: 3D 시선 벡터 평균 각도 오차 **10° 이내**  
* **지연 시간**: 영상 입력부터 결과 출력까지 **0.3s 이내**  
* **재현율**: 이상행동 탐지 성공률 **90% 이상**  

## 📅 수행 일정 (Current Status)

**5-10주차**: 파트별 모듈(얼굴/포즈) 개발 및 IR 적응 학습 진행.  
**11-15주차**: 신뢰도 융합 로직 구현, TensorRT 통합 및 최종 성능 검증.
