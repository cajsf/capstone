# 🚗 Scuppy (스꾸삐): 강건한 운전자 모니터링 시스템 (DMS)

> **2026학년도 1학기 인공지능학과 캡스톤 디자인 프로젝트**  
> **저조도 및 안면 가려짐 환경에서도 동작을 유지하는 IR 기반 운전자 모니터링 시스템**

---

## 프로젝트 개요

최근 교통사고의 주요 원인으로 지적되는 졸음운전 및 주의분산 행동을 실시간으로 감지하는 것을 목표로 합니다.  
본 프로젝트는 기존 RGB 기반 시스템의 한계인 **야간 저조도**, **급격한 조도 변화**, **마스크/선글라스 등에 의한 안면 가려짐** 상황에서도 안정적으로 동작하는 **IR(적외선) 기반 DMS** 구현을 지향합니다.

- 핵심 장비: USB IR 카메라, NVIDIA GPU 기반 개발 장비 및 임베디드 배포 환경
- 핵심 목표: 저조도와 차폐 환경에서도 중단 없는 운전자 모니터링
- 주요 접근: 얼굴/시선 정보와 포즈 정보를 결합한 멀티태스크 융합

## 팀원 및 역할

| 파트 | 담당 팀원 | 주요 업무 |
| :--- | :--- | :--- |
| 얼굴 (Face) | 강성찬, 유건 | IR 기반 얼굴/특징점 처리, 시선 추정, 얼굴 신뢰도 산출 |
| 포즈 (Pose) | 이수찬, 황영인 | 상반신/머리 포즈 추정, 차폐 상황 대응, 포즈 기반 이상행동 분석 |
| 조율 및 통합 지원 | 강민성 | 팀 간 진행 조율, 파트 간 연결, 전체 시스템 베이스라인 정리, 임베디드 배포 및 통합 지원 |

## 핵심 기술 방향

- **IR 기반 처리**: 저조도 환경과 차폐 상황에 강인한 입력 확보
- **멀티태스크 융합**: 얼굴/시선 정보와 포즈 정보를 함께 사용
- **신뢰도 기반 동적 제어**: 얼굴 confidence에 따라 포즈 정보 비중을 조정
- **실시간 추론 최적화**: 지연 시간, 온디바이스 동작 가능성, 임베디드 배포 가능성을 함께 고려

## 모델 구조 관점

이 프로젝트에서는 아래 두 방향을 구분해 다룹니다.

- **End-to-End Model**: 입력에서 최종 이상 상태 판별까지 하나의 모델 흐름으로 처리하는 접근
- **Application Pipeline**: 전처리, 얼굴/시선 추정, 포즈 추정, fusion, alert 단계를 나누어 구성하는 접근

실험과 구현은 가능한 한 이 두 방향이 혼동되지 않도록 구분해서 관리합니다.

## 정량적 목표

- 정확도: 통합 환경에서 **95% 이상**
- 시선 오차: 3D 시선 벡터 평균 각도 오차 **10도 이내**
- 지연 시간: 입력부터 결과 출력까지 **0.3초 이내**
- 재현율: 이상행동 탐지 성공률 **90% 이상**

## 진행 방향

- IR 이미지 기반 시선 추정 학습 진행
- 포즈 추정 모델 전이학습 및 파인튜닝 검토
- 얼굴 confidence와 포즈 결과를 결합하는 score-based fusion 설계
- 자체 데이터셋 구축과 augmentation 기반 백업 플랜 병행

## 개발 및 실험 환경

- Hardware: USB IR Camera (UVC 지원), NVIDIA RTX GPU Laptop
- Language: Python 3.9+
- Frameworks: PyTorch, TensorRT, OpenCV, MediaPipe
